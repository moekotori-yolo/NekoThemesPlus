# Neko Themes Plus 0.4.0 中文使用手册

## 一、安装成品包

1. 启动 Unity 2022.3 LTS 并打开目标项目。
2. 打开 **Window > Package Manager**。
3. 点击左上角 **+**，选择 **Add package from tarball...**。
4. 选择 `com.neko.themesplus-0.4.0.tgz`。
5. 等待 Unity 编译完成，Console 中不应出现 NekoThemesPlus 编译错误。

如果使用源码，选择 **Add package from disk...**，然后打开 `Packages/com.neko.themesplus/package.json`。

## 二、首次设置

1. 打开 **Window > Neko Themes Plus > 设置**。
2. 保持右上角“启用”处于开启状态。
3. 进入“背景”，点击“选择图片”。图片可以放在项目外，支持 PNG、JPG、JPEG。
4. 推荐先应用“Neko 玻璃”预设，再按显示器和图片微调：
   - 模糊：`18–24`
   - 亮度：`0.65–0.8`
   - 磨砂颜色强度：`0.65–0.78`
5. 进入“窗口”，确认层级、检视器、项目、控制台已启用。

想得到淡粉参考效果，可直接应用“樱花磨砂”预设，再进入“玻璃”修改磨砂颜色、Alpha 和强度；进入“颜色”可启用自定义文字颜色，并分别调整主文字和次要 / 提示文字。

需要把当前外观分享给别人时，进入“预设 > 分享主题 > 导出主题”。生成的 `.nekotheme` Schema 3 会内嵌全局壁纸、四张区域壁纸、磨砂颜色和文字主题参数；单张图片上限 64 MB、全部图片合计上限 96 MB。对方安装 NekoThemesPlus 0.4.0 后，在同一页面点击“导入主题”即可。旧版 Schema 1/2 主题仍可导入。原生 Windows 实验设置、强制版本兼容和调试开关不会随主题导入。

修改会自动写入当前项目的 `ProjectSettings/NekoThemesPlusSettings.asset`。背景图片保存的是绝对路径；移动或删除图片后，需要重新选择。

## 三、背景显示模式

“区域独立背景”提供层级、检视器、项目和控制台四个条目：

1. 点击“选择独立图片”为该区域覆盖全局壁纸。
2. 点击“使用全局”清除覆盖并立即恢复全局连续背景。
3. 每个实际窗口按自己的尺寸缓存处理结果，因此多个 Inspector 可以正常使用同一张独立图片。
4. 独立图片共用全局的显示模式、缩放、构图、调色、不透明度和模糊参数。

- **填充（Fill）**：保持比例并裁切，铺满整个 Unity 主窗口，推荐使用。
- **适应（Fit）**：保持比例显示完整图片，空白区域透明。
- **拉伸（Stretch）**：不保持比例，直接铺满。
- **居中（Center）**：以原始像素尺寸居中。
- **平铺（Tile）**：按原始尺寸重复。

“背景缩放”支持 1–4 倍；水平和垂直构图用于决定裁切重点，例如人物靠右时可把水平构图向右移动。

停靠在主 Unity 窗口中的面板会截取同一张处理后壁纸，因此不会在每个面板重复显示整张图。完全移到主窗口外的浮动窗口会自动显示一张本地完整背景，避免 UV 边缘拉伸。

## 四、窗口与安全限制

- Hierarchy、Inspector、Project、Console 的开关和透明度互相独立。
- Unity 2022.3 的旧式窗口通过 HostView 绘制桥实现透底；Dock 标签栏和边框可在“颜色”页面单独控制。
- 磨砂玻璃颜色的 Alpha、全局强度和窗口强度会相乘，可在不降低内容清晰度的情况下做淡色玻璃。
- 文字主题覆盖常用窗口中的 UI Toolkit 标签和 Unity 内置 IMGUI 样式；关闭开关、停用插件或恢复 Unity 时会还原原始颜色。
- 插件只改变背景层和玻璃着色层，不改变内容层 opacity。
- Scene View 和 Game View 默认关闭。开启后只处理顶部约 24 px 的编辑器工具条；3D 场景与游戏相机画面保持原样。
- Windows 原生效果全部是实验功能且默认关闭。建议一次只打开一个效果进行测试。

## 五、恢复与故障处理

正常停用：

- 使用 **Tools > Neko Themes Plus > 停用**；或
- 打开“高级”，点击“恢复 Unity”。

停用会移除注入层、还原已备份的 GUIStyle 和 DWM 值、取消事件订阅，并释放 Texture/RenderTexture。

如果上一次初始化没有正常结束，插件会在下一次启动自动进入 Safe Mode。此时仍可打开设置；确认项目可正常工作后，点击“正常启用”。

壁纸不可见时依次检查：

1. “背景状态”是否为“就绪”。
2. 背景路径对应文件是否仍存在。
3. 目标窗口开关是否开启，面板不透明度是否过高。
4. 在“高级”中点击“重建背景”和“刷新窗口”。
5. 点击“复制诊断报告”，把剪贴板内容发给维护者；重点检查 HostView 桥和内容挂钩数。
6. HostView 仍无法处理的区域，可尝试“旧式 GUIStyle 兼容”或“扩展内部样式（实验性）”；如出现异常，关闭选项并点击“恢复 Unity 样式”。

## 六、版本说明

正式目标为 Unity `2022.3.42f1`，插件会把 `2022.3.x` 识别为受支持的 LTS 系列。其他版本可以加载设置窗口，但内部窗口主题默认关闭；“强制支持当前版本”只建议用于备份完善的测试项目。
